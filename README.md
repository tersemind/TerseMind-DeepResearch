## Overview

As of **November 2026**, **TerseMind DeepResearch ranks #1 on both [DeepResearch Bench I and II](https://huggingface.co/spaces/muset-ai/DeepResearch-Bench-Leaderboard)**. Our system is built around two principles: generality and architectural simplicity. It uses largely the same architecture across both benchmarks. Selected [sample reports](https://github.com/tersemind/TerseMind-DeepResearch/tree/main/sample-reports) from our latest submissions are also available, with five in Chinese and five in English for each benchmark.

This release currently includes sample reports. We plan to open-source the system or offer API access in the future.
